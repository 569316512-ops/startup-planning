# 首页、收藏、认证恢复与快速帖聊天

## 用户反馈与改动
- 首页移除会员推广条，会员入口保留在“我的”；隐藏手机地图找房与桌面地图视图入口，保留单个帖子的高德位置链接。
- 删除详情右上举报旗帜，保留分享。
- 筛选扩充为12项生活偏好、20项房屋设施；支持宽带/Wi-Fi、独立卫生间/独立卫浴、可养宠物/接受宠物别名，多选为AND。
- 快速帖收藏新增pilot_favorites表，区别于普通帖FK；列表、详情、收藏页均返回当前账号saved，撤回级联移除收藏，过期/失效/测试帖不进入收藏结果。匿名收藏在登录后自动续接。
- 注册重复邮箱返回明确email_registered；客户端相同凭证尝试真实登录，正确则沿用原账号；错误则提示原密码并可保留邮箱切到登录。不得重置密码或覆盖已有账号，原需求及图片仍保留。
- 快速帖底部与桌面新增“在线沟通”，复用双人conversations/messages。服务端从帖子user_id决定收件人，不信客户端指定的pilot ownerId。双方block、停用、帖子失效/撤回/非公开/测试来源均校验。
- 旧匿名帖可凭管理receipt绑定登录账号，条件UPDATE只允许未绑定或同账号，不能转移其他账号。登录时自动处理本机最近有效管理凭证。无账号的旧帖不能虚构收件人或伪报消息送达；自己的帖子不能给自己聊天。
- 聊天不计入查看微信/电话的每日额度；消息按原有轮询机制更新。

## 根因与回归
- 收藏原前端主动拒绝pilot，后端favorites仅引用普通posts；实际PUT返回404。测试已复现，再新增独立表与正确读写。
- 用户注册原错误文案仅对应重复邮箱检查，不能据此推断是表单资料缺失。新测试复现request_error，修正为明确分支并验证正确/错误密码两条恢复路径。
- 真实双浏览器连续收发复现聊天页React清理异常(TypeError: l is not a function)：自动滚动effect直接返回scrollIntoView结果。改为块函数不返回值后，双用户连续收发与轮询均通过。
- 独立审查指出快速帖未统一block/停用状态，已有失败断言，再用共享pilotAudience覆盖列表、详情、收藏、联系方式和照片；聊天同样使用此策略。
- 审查指出已有账号登录后的创建账户通知不准确，改为中性“已登录”。无未处理重要发现。
