# WorkBuddy：一起租 CloudBase 独立能力探针

只部署本包验证能力，不迁移正式产品，不购买/升级/充值或开启自动续费。不得把本地通过写成云端通过。目标环境固定为 `yiqizu-mvp-test-d4fa3kk6dc43ea64`（上海），不得创建第二个环境。

## 0. 校验包与费用

1. 下载用户转交的 `yiqizu-cloudbase-probe.tar.gz`，核对另行提供的SHA256；解压至本机独立目录，运行 `node VERIFY.mjs`，必须成功。需要Node >=22.13用于本机安装/校验；云函数构建目标Node >=20，实际可用运行时版本须报告。
2. 只读确认套餐仍为免费体验、无自动付费，记录当前资源点、免费到期日和默认域名限制。若需购买/升级/独立计费COS资源，停止并报告。
3. 保存本机执行记录，不发送控制台凭证、API Key、令牌、Cookie、带签名URL、请求体或包含令牌的网络截图。

## 1. 准备隔离数据库和私有存储

1. 在该环境PostgreSQL控制台先查重：`public.cn_probe_slots`、`public.cn_probe_take_slot(uuid)`。存在任一对象则停止，不执行覆盖/删除；把现状交回。
2. 以有权执行DDL的控制台身份执行 `sql/schema.sql`。它只创建隔离探针表及RPC，要求平台现有`anon`、`authenticated`、`service_role`角色，且服务端角色有BYPASSRLS；缺角色时整笔回滚并停止。不要自行把角色改成超级用户或给访客放权。
3. 通过当前环境内的PG云存储创建专用**私有逻辑桶** `cn-probe-private`（不是另购一个COS产品/环境）。若同名桶已存在，先报告，不能假定是本探针资源。
4. 桶设为非public、限制PNG、文件大小限制设为1024字节（如控制台支持）。确认没有对该桶生效的访客/普通登录用户公共SELECT/INSERT/UPDATE/DELETE规则；不得修改其他桶。服务端API Key可管理本桶，浏览器只可凭单对象签名上传。
5. 某能力/配置不存在时停止并返回原始**脱敏**错误和页面提示，不通过开放公共读写绕过。

## 2. 配置并部署探针函数

1. 查重函数名 `yiqizu-capability-probe`；已存在则停止，不覆盖。只使用普通云函数的当前免费资源，不切换计费产品。
2. 在本机函数目录 `functions/yiqizu-capability-probe/` 执行 `npm ci --omit=dev --ignore-scripts --no-audit --no-fund`。依赖和锁文件已提供；缺网/安装失败时报告，不擅自升级SDK。上传运行依赖，入口 `index.main`（文件`index.cjs`；如控制台入口只识别index.js，报告限制，不盲改源码）。Node运行时选实际支持的>=20版本，内存256MB、超时60秒（仅当免费套餐支持，不调整付费配额）。
3. 在本机生成32字节随机值并转64位小写hex，作为`PROBE_TOKEN`；只存本机私有记录和云函数环境变量，别打印到对话。设置`CLOUDBASE_ENV_ID=yiqizu-mvp-test-d4fa3kk6dc43ea64`和服务端`CLOUDBASE_APIKEY`，API Key只存函数配置，不放静态页。
4. 仅允许指定探针函数被SDK访客调用，保留数据库/敏感RPC权限拒绝。允许匿名登录及当前测试域名调用，但不开放整个环境的匿名函数访问；若平台只能全局开放，请停下报告。
5. 不配置公开HTTP转发、不修改站点根目录。未授权请求和`health`不访问数据库和存储，不能用health成功代替完整探针。

## 3. 部署静态测试页

1. 将`static/`内容部署到现有静态托管的`/cn-preview/`目录，保留根目录“一起租访问测试成功”页面。
2. 静态资源全部相对路径，SDK已打包，无外部脚本CDN。页面CSP限制连接固定环境网关和腾讯云认证API；若实际SDK请求其他官方域名导致CSP阻断，记录准确域名和请求用途交回，不直接放开`*`。
3. 只在用户本机可信浏览器打开测试页，手动填本机探针令牌点击运行。不要把令牌写入URL、浏览器存储、分享链接或粘贴到对话。
4. 一次运行验证：SDK访客调用、PG两次并发仅一个名额、访客直读表/RPC拒绝、浏览器限定路径上传1pxPNG、同签名不能写别的路径或覆写、非public读取拒绝、服务端校验实际字节、5分钟签名读取和删除后不存在。
5. 页面报告有`not-run`是正常的“未执行”，不是通过。普通账号权限和真实资源消耗需要下一步补证。任何网络错误或404不存在表不能当成PG权限通过。不要输出原始SDK异常，可能包含令牌/URL；可记录脱敏状态码、错误码、请求ID。

## 4. 补充真实权限与额度证据

1. 用一个实际平台普通登录用户，在本机验证不能直读`cn_probe_slots`、不能执行`cn_probe_take_slot`、不能读取/写入私有桶。不要新开短信/邮件付费认证；若没有可用普通用户，则明确“未执行”并报告认证方式限制。
2. 核对平台函数请求/响应大小、实际SDK版本、PG角色/RLS配置、签名上传有效期和是否允许覆盖，以及测试前后的资源点差值。文档说明和实际结果分开。
3. 只分享页面“复制报告”的脱敏JSON和此补充记录。自动报告恒为`manual-verification-required`，不宣称正式产品或所有大陆网络已通过。
4. 若测试签名越权写入成功，会留下当前runId目录下的`other.png`；若中途失败，`pixel.png`也可能保留。将这些**精确探针路径**加入清理清单，只在确认内容是本次1pxPNG后删除，不清空桶。

## 5. 返回结果和收尾

返回：包SHA、环境/地域、Node/SDK版本、函数部署版本和入口、SQL执行结果、私有桶/RLS检查、预览URL、脱敏JSON、普通登录用户权限结果、请求大小/签名期限/资源点变化、未通过项目及仍留存的精确探针资源。

SQL探针行可保留供核对；需要清理时只删除报告runId对应行，不DROP表或修改业务数据。完成后清空/撤销`PROBE_TOKEN`令牌，禁用探针函数的访客调用权限；页面仍可显示但受保护操作拒绝。只处理本探针函数，不影响后续正式`yiqizu-api`或其他资源。API Key若为专为本探针创建且不被其他服务使用，可以在本机撤销并报告状态。
