## 当前发布与联系流程

- 手机首页直接突出“有房找室友”和“无房找住处”入口，删除原介绍口号。
- 有房登记在称呼后填写职业；最后三项勾选已移除，提交按钮附近直接说明成年、公开字段及用途。原始户型确认保留。
- 发布者主动选择联系方式范围，无默认勾选：登录用户可查看，或仅运营可见。旧登记默认仅运营可见。普通登录不代表手机或身份认证。
- 大于512KiB的照片上传前缩至最长边1600px以内并转JPEG（质量0.82），仅采用比原图小的结果；最多2张并行上传，显示进度，失败重试保留成功照片。
- 正式登记成功后可进入刚发布的帖子，昵称、职业、区域、预算/租金、介绍、房屋信息和照片按发布说明展示；结构化联系方式只经专用授权接口返回。
- `?src=test&qa=1` 是测试入口：登记不会进入公开广场、详情或照片接口，成功页不再冒称已公开发布，并提供切换正式发布入口。真实发布请用 <https://yiqizu-guiyang.coppershark1.chatgpt.site/?city=贵阳>。
- 按上海日历日，普通账号每天最多查看5个不同联系方式身份，重复查看不重复计数；凭本机管理凭证可随时关闭展示。

包含0000至0009迁移，旧库按顺序追加未应用迁移，旧迁移不修改。源码功能与部署状态分开记录，线上版本以发布记录为准。

## 已实现

- R2 图片上传，JPEG/PNG/WebP，每张5MB以内；快捷登记最多12张，完整发布最多8张。
- 可解释习惯匹配；问答建档和AI推荐入口目前隐藏，旧实现保留。
- 详情外链高德搜索、合租约定文本下载、浏览器本地看房清单；地图找房入口目前隐藏。
- 推广申请保存在服务器，支付渠道接通前不扣款、不展示付费推广。
- 桌面和移动端适配，可分享的帖子链接与保存在URL中的筛选条件。

## 运行

Node.js >=22.13，建议24；npm或对应包管理器。

专用本地验收环境（不使用生产账号、D1或R2）：

```sh
npm ci
npm run build
CONTACT_BROWSER_QA=1 node scripts/start-member-test-server.mjs
```

访问 http://127.0.0.1:5188 。测试服务自动应用所有现有迁移，数据保存在忽略目录`.wrangler/member-tests/v3/`。

另开终端运行示例检查：

```sh
npx tsc --noEmit --incremental false
node scripts/member-smoke-test.mjs
node scripts/member-race-test.mjs
node scripts/profile-edit-test.mjs
node scripts/post-edit-photos-test.mjs
node scripts/smoke-test.mjs http://127.0.0.1:5188
```

新库先运行member-smoke，以初始化并发测试依赖的虚构管理员。浏览器脚本依赖Playwright和Chromium，部分导入路径对应验收cloud环境；换环境时需调整路径。完整23组记录见根目录验收报告。脚本只面向独立本地测试环境，勿指向生产。

开发命令`npm run dev`通常使用5173端口；需要自行准备对应本地DB/R2与全部迁移。仅在变更schema时生成新的迁移，不要把`db:generate`当作启动步骤。

## 数据与配置

`.openai/hosting.json` 绑定 `DB`（Cloudflare D1）与 `BUCKET`（R2）。公开页面未登录可浏览，完整发帖/普通帖子联系/收藏需要本站账号；所有新增发布需要登录，以便共享每日额度。当前原站点已配置为public，普通访客不需要ChatGPT登录；发布、收藏和联系使用本站账号。

可选运行环境变量，通过本地忽略的 `.dev.vars` 或 Sites 环境变量工具设置：

- `ADMIN_EMAIL` 与 `ADMIN_SETUP_TOKEN`：管理员首次建档需邮箱与私有引导令牌同时匹配。令牌仅在服务器配置，普通网页注册不能成为管理员。可用 `scripts/create-admin.mjs` 从本地终端完成初始化；不要把令牌写入源码。
- `AI_API_KEY`：真实大模型接口密钥，仅在服务器使用。
- `AI_BASE_URL`：OpenAI兼容接口地址，默认 https://api.openai.com/v1。
- `AI_MODEL`：默认 gpt-4.1-mini；按照实际账户可用模型设置。
- `AMAP_API_KEY`：可选的高德 Web 服务 Key。配置后，发布房源时会按小区位置补全经纬度、最近公共交通和附近生活配套；未配置时保留发布者填写的信息，并提供高德地图核对入口。

当前没有邮箱验证或密码找回服务；没有短信登录。默认聊天未移植上游E2EE协议，而是HTTPS及成员权限保护。部署侧HTTPS由平台提供。

## 演示与外部能力

示例房源和用户由 `lib/demo.ts` 生成，全部虚构，图片为Unsplash场景示意。示例不会写入生产数据库，不能联系、收藏或登记真实意向。主页可关闭示例数据。无图真实帖展示暂无照片的占位状态。

真实身份/征信/背景调查、支付平台自动回调、邮件通知均未接入；会员支持个人收款码与付款截图人工核实，当前线上收款码未配置，付款关闭，不伪造通过状态。管理员核实身份后才能显示人工验证标记。截图OCR导入按需求文档保留为后续计划。

当前自然语言AI仅做资料和租房问题咨询，不自动访问实时房源；相同习惯排序是确定性比较。公开招募前待补运营信息、正式隐私说明与验收报告中的缺口；免费MVP可保持收款关闭。

源码来源及具体复用见 `UPSTREAM.md`。原RoomDate Go服务和React源码留存在 `upstream/roomdate/`；当前上线使用TypeScript/D1适配层。

## 手机优先的快速验证试点

- 首页允许先填写“2分钟登记需求”，发布时必须登录；注册仅邮箱和密码。有房至少上传1张照片，求租个人照片可选，均允许继续添加多张。按提交按钮附近的发布说明发布，联系方式遵循用户单独选择的范围。
- 手机底部固定入口，桌面首页保留；手机不下载大型头图，默认不混入演示帖子。
- `?view=pilot-admin` 为负责人运营看板，仅服务器配置的 `PILOT_OWNER_EMAIL` 对应的受信 Sites 登录身份或本站管理员可读。生产变量由平台管理，不放源码。普通用户不需要 ChatGPT 登录。
- 新迁移：`drizzle/0001_icy_sentinels.sql`，新增私有登记与会话级漏斗事件；旧迁移不修改。
- 私有联系方式不在公开 API 返回。文字与房屋信息自动保存为本机草稿；用户本机保存多条随机撤回回执，可继续登记并逐条删除。照片返回后需重新选择。超过30天的登记在后续登记或运营访问时清理。旧私有登记不得自动公开；仅展示带公开标记且非测试来源的有效登记。
- 渠道来源：`src=wechat_group`、`colleague`、`friend`、`xiaohongshu`、`direct`；`src=test&qa=1` 用于验收，测试登记不计入汇总。
- 看板会话数不是独立访客数，运营已联系人数不是双向匹配对数；真实需求与约看房需人工核实。
- 本地检查：先应用新迁移，再启动 Wrangler 并配置虚构运营身份 `--var PILOT_OWNER_EMAIL:pilot-owner@test.local`，执行 `node scripts/pilot-smoke-test.mjs http://127.0.0.1:5188`。脚本仅支持本地地址，使用虚构资料并撤回测试登记。
- 通用验证技能与生成器在仓库 `validation-kit/`；贵阳市本轮执行包在 `validation/yiqizu-guiyang-2026-10-15/`。大陆实机验收与真实招募尚不能由自动化测试代替。

## 首页与快速帖账号能力
首页不展示会员推广条，地图找房暂隐藏；详情保留位置外链并去除举报旗帜。筛选提供12项生活偏好和20项房屋设施，兼容常见同义写法。

快速帖支持登录收藏、收藏页与站内聊天。旧匿名帖可凭本机管理凭证绑定账号，不能抢占已有绑定；遗失管理凭证不能仅凭手机号/邮箱猜测归属。已绑定帖聊天由服务端解析真实发布者，自己的帖子不能给自己发送消息。重复邮箱正确凭证可恢复原账号登录，错误凭证明确提示登录，不重置密码或覆盖账号。
