# MVP首轮运营准备与验收修复

本轮以公开推广前验收QA-01/02/03为范围，保持免费试点、付款未配置。功能代码完成不代表运营资料和邮件能力已经上线。

## 必填真实配置

通过Sites运行环境配置；不要把密钥、真实联系资料误写入示例文件或提交运行环境文件。

| 配置名 | 用途 |
| --- | --- |
| OPERATOR_NAME | 对外展示的真实运营者名称 |
| SUPPORT_EMAIL | 可实际接收反馈、数据请求的对外邮箱 |
| RESEND_API_KEY | Resend服务端发信密钥，作为secret配置 |
| MAIL_FROM | Resend已验证域名下的发信地址，如 `一起租 <noreply@你的域名>` |
| RESET_PUBLIC_ORIGIN | 正式网站HTTPS origin，默认当前一起租站点；发信链接不信任请求Host |

目前仅有PILOT_OWNER_EMAIL配置，不能把它自动当作获准对外公开的客服邮箱。运营名称缺失时界面提示受控内测；发信参数缺失时找回接口503，不能声称邮件找回已可用。真实发信开启后，需要运营用自己的测试邮箱确认收件、垃圾箱、过期和重复点击行为。不要把真实邮件测试密钥写入聊天。

## 帮助与反馈

手机注册处、页面底部及「我的」均提供帮助入口。说明覆盖数据类别、用途、公开范围、托管与发信处理方、保存现状及删除/注销请求方式；不捏造主体、保存期限或处理时限。

访客可选择功能问题、内容投诉、个人数据/注销、账户问题、其他，填写说明与回复联系方式。接口按IP每小时限5次，仅运营可读。提交后返回编号；运营在试点看板或审核工作台查看、通过所留联系方式核实和回复，再标记已处理。标记状态不会自动删除账户或完成数据处理。请至少每天检查一次反馈和消息。

数据请求须先验证账户归属。不能因为对方自述邮箱就交出聊天记录、重置密码或删除他人帖子。对具体删除操作及依法保留的数据要逐项核实并向请求者解释。

## 密码恢复

新增 `password_resets`、`support_requests` 表，对应迁移0010；已有库只追加迁移，不重建历史数据。

- 邮件发往注册邮箱，包含32字节随机令牌。数据库仅存SHA-256；15分钟有效、一次使用。
- 链接令牌在URL fragment中，应用读取后立即从地址栏移除，不写入localStorage、不放入查询参数或分析事件。
- 请求发送邮件统一返回提示，不在响应中暴露账号是否存在或重置令牌；配置缺失时所有邮箱均返回503。未做严格的全链路时序侧信道或渗透审计。
- IP和邮箱请求限频；发信失败删除本次令牌并仅记录无个人信息的错误。统一成功提示不保证实际送达，须配置真实收件测试与运营检查。
- 有效令牌绑定当时密码hash，密码改变后旧链接失效。D1原子batch认领令牌、更新密码并撤销该用户所有会话；并发同一/不同链接均最多一个成功。其他用户会话不受影响。
- 不存在人工口述邮箱改密，也不返回开发用重置令牌。测试仅在独立数据库插入fixture，生产没有测试后门。
