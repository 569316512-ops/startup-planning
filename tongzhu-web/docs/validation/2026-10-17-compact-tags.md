# 标签高度与会员入口微调（2026-10-17）

标签容器为卡片对齐预留26px时，默认flex stretch把标签本身拉高。保留容器留白，改align-items/align-content:flex-start，使标签按文字、内边距与细边框自然高度排列。删除globals.css中700px断点残留的最后一个标签隐藏规则，四个标签均能展示，继续保持卡片同行等高。

会员按钮改浅紫底、紫字、1px细边框、较轻字重，移除阴影并缩小内边距；手机规则同步。个人介绍保存按钮未改。

本地浏览器以房源四短标签/求租空标签对比，在360/395/493/602/731/1280验证每个标签实际高度不超过文字行高+内边距+边框、四标签均可见、卡片继续等高、无页面溢出。会员实际计算样式浅紫rgb(243,239,249)、字色rgb(113,91,158)、1px边框、无阴影，无浏览器异常。构建及diff检查通过。没有功能/API/数据库改动；原编辑浏览器用例的会员颜色预期同步调整。
