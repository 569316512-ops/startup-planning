# 手机端独立设计与排版验收

日期：2026-10-15

## 参考图中借鉴的原则

依据用户提供的两张贝壳手机截图，借鉴城市与搜索靠前、照片卡片、价格层级、分块详情、固定底部操作。保留一起租的紫色品牌与合租匹配场景；不使用参考图中的品牌、照片、广告文案、用户数量或认证标签。未核实任何市场份额说法。

## 实现

- 手机端采用独立组件 `components/mobile-discovery.tsx` 与独立样式 `app/mobile.css`，700px 及以下启用；PC 保留原有首页和详情布局。账户、列表、筛选、登记数据仍共用。
- 手机首页：城市 / 地图入口、紧凑搜索、区域与预算入口、两个登记入口、推荐分类、双列图片卡片。房源位置小图标保留，长标题限两行，价格清晰展示。
- 底部导航：首页、收藏、登记需求、消息、我的；不显示虚构红点或用户数量。
- 详情页：照片与缩略图、租金及核心信息、位置、发布者、详细描述依次排布；底部固定收藏、聊天、联系。原有合租意向入口保留在发布者卡片中。
- 登记弹窗：头部与关闭按钮固定在弹窗内，仅内容区滚动；背景页面锁定滚动。联系方式改单列，日期与其他输入保留 16px 字号，支持安全区与可用高度变化。

## 验收证据

| 场景 | 浏览器模拟尺寸 | 结果 |
| --- | --- | --- |
| 首页、双列卡片、长标题 | 360×800、390×844、430×932 | 文档 scrollWidth 未超过 clientWidth；卡片内容未越过页面边界 |
| 房源详情、生活习惯、底部联系 | 同上 | 文档未横向溢出；各信息块及联系按钮未越界 |
| 登记弹窗 | 同上，另加 390×480 | 内容区 scrollWidth=clientWidth；弹窗在可用高度内，关闭入口可见；联系方式单列 |
| 长地区名称 | 重庆“秀山土家族苗族自治县” | 选择成功，无横向溢出 |
| PC 首页 | 1280×900、1440×1000 | 无横向溢出；原首页显示，手机组件隐藏 |
| PC 详情 | 1440×1000 | 保持正文 / 联系人双栏，手机底部联系隐藏 |
| 功能专项 | 本地预览 | 匿名登记、去重、权限、状态更新、字段校验、撤回和测试数据排除通过 |

类型检查与正式构建通过。本地房源卡片排版使用明确标记的虚构测试资料，未发布到生产。线上没有真实房源时保留空状态，不将测试资料伪装为供给。

390×480 是缩短可用高度检查，不能替代 iOS / Android 真机键盘、微信及大陆网络验收。
