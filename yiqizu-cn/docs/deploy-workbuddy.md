# WorkBuddy：一起租国内H5受控预览部署

本包是本地验证后的预览候选，不是上线验收通过。只用现有上海环境`yiqizu-mvp-test-d4fa3kk6dc43ea64`、免费现有资源；不购买/升级/充值/开自动续费，不改原Sites、站点根页或无关资源。默认域名只供受控测试，不公开投流。

## 本机构建与检查

GitHub固定检出用户提供的已推送commit到新目录，不覆盖旧工作目录。Node>=22.13，`npm ci --ignore-scripts`，`npm run typecheck`、`npm run build`、`npm run build:api`、`npm run package:preview`。本地完整PG测试已由Codex执行；本机没有专用PG容器时不要伪造测试通过。包`release/yiqizu-cn-preview.tar.gz`解压到独立目录，`node VERIFY.mjs`应全通过。BUILD字段必须仍标businessCloudVerified:false/productionReady:false。

## 备份与查重

先记录套餐/到期/无自动付费、资源点；确认环境与地域。保存现有`/cn-preview/`探针4个静态文件的本机备份，以便回退；根index.html保留。查`yiqizu-api`函数、`cn-photos-private`私有桶、`cn_migrations`及9张业务表。首次不存在才创建；重名但来源无法确认立即停止，不覆盖。

探针已完成收尾，不能复活旧PROBE_TOKEN或专用key；业务使用新建本机专用服务端APIKey，凭据仅本机/云函数保存，不进对话、快照、剪贴板分享或仓库。沿用当前免费PG逻辑存储，不另开收费COS。

## 数据库

首次查重无业务表才按序执行`migrations/0001_core.sql`至`0005_operations_cleanup.sql`。每个文件整笔事务且在cn_migrations登记，不重置库；重复执行同版本不删除数据。出现角色缺失/SQL错误，停止并报告脱敏SQLSTATE，不给anon/authenticated加权限。实际迁移数量以包中排序文件为准。

核实9张业务表强制RLS，PUBLIC/anon/authenticated无直接权限；所有cn_敏感RPC仅service_role可执行。用有效匿名令牌和真实普通账号验证表、RPC、桶读写被拒绝，记录结构化错误码；未登录401/表不存在404不是权限证据。

## 云函数与私有桶

创建`cn-photos-private`，private，允许image/jpeg、image/png、image/webp，控制台支持时单文件上限5MB。无访客/普通平台账号的读写/签名策略，服务端key管理；浏览器仅凭指定对象签名上传。

函数目录执行`npm ci --omit=dev --ignore-scripts --no-audit --no-fund`再上传含运行依赖的ZIP。普通云函数`yiqizu-api`，入口`index.main`，Node20.19或现有免费支持>=20，256MB/3秒，关闭自动安装依赖。设置CLOUDBASE_ENV_ID和新的CLOUDBASE_APIKEY；不配置公开HTTP入口。

仅放通本函数的已登录CloudBase传输身份（包括匿名登录），不要开放所有函数。OPA只限functions资源和本函数精确路径或路径后缀，沿用探针实际验证的规则语法。数据库/存储维持默认拒绝。不要顺带恢复yiqizu-capability-probe权限。

## 静态预览与可信身份

将static/内容上传到`/cn-preview/`（可覆盖已备份的探针文件），清理旧探针静态脚本时仅精确4个已备份文件。不得替换根测试页。CSP错误只报告实际官方域名及用途，不放开*。允许匿名登录已开，配置此测试域名。

业务注册限频只读取平台调用context中的TCB_UUID或TCB_SOURCE_IP，忽略event内伪造值。需实测证明这些字段由平台注入且客户端无法覆盖；只报告字段是否存在/来源，别输出完整IP或身份值。若缺字段注册会503，停止并报告，不以客户端自报IP/随机ID绕过。

## 管理员开通（不按未核验邮箱自动授权）

公开注册永远是普通用户。由用户在本机创建自己的运营账号并登录，在自己的应用资料响应中读取用户UUID；不要把密码或会话发给Codex。若邮箱已被未知人注册，停止，不直接授权该账号。

用户在本机确认UUID和邮箱确属自己的新账号后，控制台以精确UUID及邮箱双条件执行一次UPDATE cn_users SET role='admin' WHERE id='<本机UUID>' AND email='<本机邮箱>'；要求恰好1行。让用户退出重新登录，验证普通账号不能访问运营，运营能访问。撤销管理员用同样双条件SET role='user'并DELETE该用户所有cn_sessions，不能仅修改环境变量。

## 必须实测的业务验收

1. 注册、登录、退出、改密后全部会话失效；伪造role/ownerId/oai头不能提权。记录真实冷/热耗时，特别是注册、上传核验与首次详情；3秒超时不能以本地通过替代。
2. 分别发布有房/求租，资料预填不覆盖手填/清空；求租无设施/合租要求；房东/中介有独立权限确认。我的帖子修改同一ID，冲突409不丢内容，撤回不再公开。
3. 每日3次发布、5个不同联系对象并发不超额；重复不重复扣。公开列表/详情/照片接口不泄漏联系方式，operator范围普通用户不能读取。
4. 12张以内JPG/PNG/WebP、5MB限制、文件头核验、失败重试；签名上传约60秒须立即用，同签名不能越路径或覆写。照片撤回后停止新签链接，已有短链最长300秒。
5. 运营翻页>200、跟进/下架/反馈；清理按钮每次1对象，失败可重试；45/150天保留，半年外排除。计量按小时刷新，记录资源点前后差值。
6. 在手机Wi-Fi/流量、微信/普通浏览器实际完成注册→发帖→修改→联系→退出；补移动/联通/电信记录，标设备/网络/时间。缺线路标未执行。

仅使用本轮虚构测试资料；结束按UUID精确清理测试账号、帖子、额度/测试事件和对象，保留真实运营账号与用户数据，不清空桶或DROP表。业务APIKey若保留供预览，明确有效期与用途，不误撤其他服务key。

## 返回与回滚

返回预览链接、包来源commit/SHA、迁移版本、私有桶/角色权限结果、业务验收逐项结果、冷/热耗时、资源点、真机记录和所有未通过项。不要回传任何密钥/会话/签名URL。

失败先关闭yiqizu-api临时调用权限，静态恢复已备份探针页（探针仍保持禁用）。保留SQL数据与函数版本；只增量修正，不用DROP回滚、不覆盖真实数据。修复确认前不切根目录、不邀请真实用户。公开运营主体/联系信息尚未配置，默认域名也不适合广泛推广；受控测试通过后再另核正式域名/套餐/备案条件。
